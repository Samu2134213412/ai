Zeig mir deine Seite

Zieh eine Seite aus GoodNotes hierher, füge sie ein oder tippe 📄 Seite (am Handy: Foto aufnehmen).

  1. GoodNotes: Teilen → Seite exportieren → Bild (PNG) oder Auswahl kopieren
  2. Hier: einfügen, ablegen oder aus „Dateien“ wählen (auch PDF)
  3. Schalte 👀 Darf zuschauen ein – dann liest, zeigt und schreibt der Blob auf deiner Seite.

⚙︎ Einstellungen

Der Tutor läuft über Ollama auf deinem Mac/PC im selben WLAN. Dort starten: OLLAMA_HOST=0.0.0.0 OLLAMA_ORIGINS="*" ollama serve

PC

Nur wirklich eingetragene Programme, nur während einer Fokus-Sitzung. System-Programme werden nie beendet.

iPad

📱 Handy verbinden

Handy und PC im selben WLAN. Kamera-App öffnen, QR-Code scannen, Link tippen. Fertig – der Tutor läuft dann im Handy-Browser und nutzt das Ollama dieses PCs.

Beim ersten Mal fragt die Windows-Firewall: Zugriff zulassen (nur „Private Netzwerke“). Auf dem iPhone: Teilen → Zum Home-Bildschirm. Der Link gilt nur, solange der Handy-Zugang an ist.

Welches Fenster soll der Tutor sehen?

Wähle z. B. das GoodNotes-Fenster. Der Tutor sieht nur dieses Fenster, solange die Freigabe läuft.
